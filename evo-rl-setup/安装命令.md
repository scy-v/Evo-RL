# Evo-RL 环境安装与模型准备

本机环境、UR 推理依赖和官方 tokenizer 已安装。下面用于重新搭建环境；日常运行见 [训练命令](训练命令.md)。

## 1. 安装环境和全部依赖

```bash
cd /home/suchenyu
git clone https://github.com/scy-v/Evo-RL.git
cd Evo-RL
conda create -y -n evo-rl python=3.10 pip ffmpeg=7 -c conda-forge
conda activate evo-rl
unset PYTHONPATH
CUDA_VISIBLE_DEVICES='' uv pip install --python "$CONDA_PREFIX/bin/python" \
  --default-index https://pypi.tuna.tsinghua.edu.cn/simple \
  -e '.[pi,ur5e]' 'torch==2.7.1' 'torchvision==0.22.1' 'torchcodec==0.5.0' \
  'pytest>=8.1,<9' pytest-timeout
```

`pi` 包含 PI05 模型依赖，`ur5e` 包含 UR RTDE、DH 夹爪、RealSense 和绘图依赖。推理时无需重新安装。

## 2. 准备官方 tokenizer

HF 账号需有 PaliGemma 访问权限；本机已缓存，可跳过。

```bash
hf auth login
hf download google/paligemma-3b-pt-224 \
  --include 'tokenizer*' 'special_tokens_map.json' 'added_tokens.json' 'config.json'
```

已有训练时使用的完整 tokenizer 目录时，可在两套推理 YAML 中设置 `model.tokenizer_path`；默认 `null` 使用官方名称及 HF 缓存。

## 3. 日常激活

```bash
conda activate evo-rl
cd /home/suchenyu/Evo-RL
unset PYTHONPATH
```

已 clone 的仓库不重复执行克隆；依赖变化后在仓库根目录重跑安装命令中的 `uv pip install` 部分。环境版本与验证范围见[安装状态](support/安装状态.md)，模型准备见[训练命令](训练命令.md)。
