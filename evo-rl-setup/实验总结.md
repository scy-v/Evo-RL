# 实验总结

## ● 2026-11-14

### 第一次实验：ACP 真机定性测试（启动时间未记录）

用户测试 ACP 5000、20000 步权重后，反馈整体至少与 SFT 相当、无明显退化，轨迹更平滑。这为本次复现的实际可用性提供了初步支持，尚未量化成功率提升。

结合用户此前在 RLinf 上的复现体验，本次真机推理结果至少支持将 Evo-RL 这边的复现视为成功跑通并取得可用效果；这是当前测试范围内的定性结论，不代表已证明性能优于 RLinf。

#### 实验条件

- **任务与模型**：UR5e 黑色架插入蓝色槽；`checkpoints/acp/round_001/checkpoints/{005000,020000}/pretrained_model`。训练池为 300 条、105610 帧，包含 RLinf rollout，与当前 Evo-RL 部署存在差异。
- **评估口径**：重点观察相对 SFT 的变化；各组次数、人工帮助、运行日志及 ACP/CFG 开关未记录，不能用当前 YAML 回填。

#### 实验结果

| 比较项 | 用户反馈 |
|---|---|
| ACP 相对 SFT 的整体表现 | 至少相当，未观察到明显退化 |
| 轨迹表现 | 更平滑 |
| 5000 与 20000 步的差别 | 未提供分组结论 |

#### 分析与结论

**1. 部署已有初步效果证据。** 本轮已运行真实 ACP 权重，但定性反馈不足以证明完整复现了论文的性能增益。

**2. 平滑度与成功率分别判断。** 轨迹更平滑是本轮观察，尚不能推断任务成功率提高或更晚 checkpoint 更好。

**3. 数据与部署差异仍未隔离。** RLinf rollout 与当前部署的差异可能影响表现，目前没有受控对照来判断影响大小。

#### 后续决定

- **待验证**：正式训练完成后，将最终权重与已有 checkpoint 在相同部署条件下比较，保留实际开关配置及每组结果；本轮反馈不用于选择最优训练步数。

## ● 2026-11-11

### 第一次实验：PI05 SFT 真机推理效果复盘（启动时间未记录）

用户反馈 Evo-RL SFT 推理有效，但明显不如其他 repo 微调模型。这是跨仓库定性比较，尚不能确定差异来自训练还是部署；日期为反馈日期。

#### 实验条件

- **任务与权重**：UR5e 黑色架插入蓝色槽，`checkpoints/sft/pi05_ur5e_insert_black_rack/run_01/checkpoints/030000/pretrained_model`；19 维状态、两路 RGB、7 维动作。反馈未绑定具体运行日志、次数或人工帮助记录。

#### 实验结果

| 项目 | 已知结果 |
|---|---|
| SFT 真机表现 | 有效果，但用户认为弱于其他 repo 的微调模型 |
| 定量评估 | 无统一条件的成功率；历史旧入口日志无成功/失败字段 |
| 训练证据（后续补核） | 30000 步训练日志及耗时已找到，见[结果摘要](summary.md)；不能仅凭训练完成判断泛化 |

#### 分析与结论

**1. 控制方式可能影响表现。** 旧入口逐动作发送控制力，新入口可持续反馈更新；尚未验证它是否解释跨仓库差异。

**2. 执行节奏未形成受控对照。** 两入口现已对齐为预测 50 步、执行前 10 步、20 Hz；不能回填为历史测试条件。

**3. 训练与部署因素尚未分离。** 两入口共用模型加载与预处理；配置核对未发现核心参数被擅自修改，但不足以排除训练量、数据或部署差异。

#### 后续决定

- **配置已修改、对照待开展**：保留旧入口，新增可开关持续力控的独立评估入口。旧入口、新入口关闭/开启持续力控三组的受控比较仍未完成；11 月 14 日 ACP 定性测试未替代该对照。实现证据见[测试进展](测试进展.md)。

## 实验总结更新规则

1. **日期与实验编号**：二级标题只写 `## ● YYYY-MM-DD`，最新日期在前；同日三级标题按时间顺序写“第一次实验：主题（启动时间）”“第二次实验：……”。跨日按启动日归档并注明实际起止；启动验证/短跑不混入正式实验计数。
2. **固定结构**：每次实验先用一小段给结论，四级标题按“实验条件 → 实验结果 → 分析与结论 → 后续决定”组织，无内容可省略。具体问题用加粗编号，数据比较用表格，不再层层增加标题。
3. **篇幅与格式**：分析保留3～4个核心问题，每项通常不超过2个要点；同级内容统一格式，数值对比集中用表格。补充证据时替换或合并旧表述，不在原结论后连续追加解释；完整方法、逐项复核和讨论过程放支持报告。
4. **聚焦实验分析**：只记录与本次训练表现、原因判断及后续实验选择有关的内容，保留核心数据、依据和限制。概念教学、一般公式解释、代码修复和回归检查不写入本文件；合并重复讨论，完整报告和计算用链接引用。
5. **冻结实验条件与边界**：以运行时归档配置为准，记录运行路径、resume来源、checkpoint、样本量、时间和单位；注明成功是否含人工帮助。日志终点与最后checkpoint分开，跨resume统计注明来源，后续配置不能覆盖旧条件。操作者干预方式或时机改变时注明其自述，区分当轮人工成功与对后续训练的影响。
6. **区分事实与推断**：明确实测结果、解释和未验证假设；均值不代表逐样本准确，相关性不等于因果，离线探针不等于真机表现。
7. **写清方案状态**：区分拟采用、配置已修改、已运行、已验证；说明关键参数与选择理由，不把建议写成效果保证。
8. **补充与更正**：同一次运行的中途/最终分析并入对应实验，注明截止范围；结论变化说明依据，不把阶段报告重复写成新实验。后续实验已运行时更新旧方案状态；规则始终置于文末。
9. **文件分工**：本文件记录实验分析与决定；代码改动及回归见[测试进展](测试进展.md)，操作见[训练命令](训练命令.md)，跨实验结论见[结果摘要](summary.md)，避免整段重复。
